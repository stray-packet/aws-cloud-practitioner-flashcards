# Chat 2 — IAM, CloudFront & Monitoring

- Authentication verifies identity; authorization evaluates allowed actions and resources.
- Protect the root user with MFA and reserve it for tasks that explicitly require root credentials.
- New IAM identities receive no permissions merely by existing; grant only the least privilege required.
- Common IAM policy elements include Effect, Action, Resource, and optional Condition.
- Amazon CloudFront is a CDN that caches HTTP/HTTPS content at edge locations; invalidations remove cached objects before normal expiration.
- Amazon S3 provides Regional object storage even though general-purpose bucket names use a global namespace.
- Amazon CloudWatch provides metrics, logs, alarms, dashboards, and observability integrations.
- Standard EC2 metrics do not include guest-memory utilization without an installed agent or custom metric.
- AWS Budgets alerts on actual or forecast cost but does not impose a hard spending cap.
- AWS Cost Explorer analyzes historical cost and usage; Budgets watches thresholds and forecasts.
