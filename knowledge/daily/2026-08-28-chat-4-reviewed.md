# Chat 4 — Edge, Private Connectivity & Compliance

- High availability minimizes interruption through redundancy and recovery; fault tolerance aims to continue operating through component failure. Fixed percentages are not universal definitions.
- CloudFront caches web content; Global Accelerator improves network paths and provides static anycast entry points without caching.
- S3 Transfer Acceleration improves long-distance transfers to S3 through edge infrastructure.
- Local Zones extend selected AWS infrastructure near metropolitan areas; Wavelength places infrastructure in communications-provider networks.
- Gateway VPC endpoints support S3 and DynamoDB through route-table entries with no additional endpoint charge.
- Interface endpoints create ENIs with private IP addresses, use AWS PrivateLink, and normally have hourly and data-processing charges.
- AWS Direct Connect provides dedicated connectivity from customer locations to AWS.
- AWS Outposts installs AWS-managed infrastructure at customer premises.
- SCPs are permission guardrails rather than permission grants; AWS Config records configurations and evaluates compliance rules.
- Data residency concerns storage location, while data sovereignty concerns the governing legal jurisdiction.
