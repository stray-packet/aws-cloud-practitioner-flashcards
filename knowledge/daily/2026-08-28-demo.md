## Shared responsibility model

AWS is responsible for security **of** the cloud. Customers are responsible for security **in** the cloud. The exact boundary varies by service abstraction: customers patch guest operating systems on Amazon EC2, while AWS operates more of the software stack for managed services such as Amazon RDS.

## Least privilege

Grant only the permissions required for a task. Protect the account root user with MFA and do not use it for routine work.

## Storage selection

Amazon S3 provides object storage, Amazon EBS provides block storage for EC2, and Amazon EFS provides a shared file system.

## Cloud benefits

Elasticity means acquiring and releasing resources as demand changes. Variable expense can replace large upfront infrastructure investments.

## Global infrastructure

Regions contain multiple isolated Availability Zones. Amazon CloudFront uses edge locations to cache content closer to viewers.

## Cloud economics

Savings Plans exchange a compute usage commitment for discounted pricing. Cloud consumption supports variable expense and reduces the need to provision for peak capacity in advance.

## Cost management

AWS Budgets monitors thresholds and sends alerts. AWS Cost Explorer analyzes historical and forecast spending.
