# Chat 1 — Cloud Foundations & IaC

- Amazon SQS provides durable message queues for asynchronous decoupling; Amazon SNS provides publish/subscribe fan-out.
- Amazon EC2 provides resizable virtual compute with customer control of the guest operating system and application stack.
- Amazon RDS manages relational database infrastructure while customers retain responsibility for data, access, schema, and workload configuration.
- IaaS removes ownership of physical infrastructure without removing administration of guest operating systems, applications, and data.
- AWS consoles, CLIs, SDKs, and infrastructure-as-code tools ultimately invoke service APIs; “single unified API” is a mental model, not one AWS product.
- Infrastructure as Code makes provisioning repeatable, reviewable, version-controlled, and automatable.
- Terraform uses provider APIs to converge infrastructure toward a desired state; it is not an application compiler.
- The informal CSP tier taxonomy, vendor rankings, and historical launch trivia remain context rather than CLF-C02 memorization targets.
