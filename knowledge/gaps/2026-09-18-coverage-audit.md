## Coverage policy

- `Studied chats` contains only concepts explicitly covered in the supplied course/chat reports.
- `Extra` contains concise cards added from the official CLF-C02 scope audit.
- The visual Services deck contains the complete current official list plus a separately labeled supplementary set for useful course-only services.
- Because AWS states that the in-scope list is non-exhaustive and subject to change, future audits should compare against the official guide again rather than treating this file as permanent.
