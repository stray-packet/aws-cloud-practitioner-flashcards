# Knowledge inbox

Drop raw Gemini exports and study notes in this folder. These source files stay local and are ignored by Git so personal chat content is not published accidentally.

Preferred filename:

`YYYY-MM-DD-topic-source.txt`

Examples:

- `2026-08-28-cloud-economics-gemini.txt`
- `2026-08-29-iam-shared-responsibility-notes.txt`

One file per study day is ideal, but multiple files for the same day are supported. Plain text and Markdown are both acceptable. Keep the original wording, including doubts, corrections, examples, and quiz mistakes.

After review:

1. Reviewed studied material goes to `../daily/` as structured Markdown.
2. Missing or adjacent topics go to `../gaps/` and require user approval before inclusion.
3. Proposed flashcards go to `../../flashcards/drafts/`.
4. Only user-approved cards are promoted to `../../flashcards/approved/` and exported to Anki.

Do not place passwords, API keys, account identifiers, or other secrets in the source files.
